# Weekkly SaaS Application

A modern weekly planner and subscription productivity web platform built with React 18, Vite, Swiper, and Progressive Web App (PWA) support.

## Overview

`weekkly` is designed for weekly goal-setting, agile sprint planning, and subscription tracking featuring PWA offline caching (`vite-plugin-pwa`), touch carousels (Swiper.js), smooth view transitions, and Firebase Hosting.

## Tech Stack

- **Frontend Core**: React 18 & [Vite](https://vitejs.dev/) (v4)
- **PWA & Offline**: `vite-plugin-pwa`
- **Animations & Carousels**: `react-reveal`, Swiper.js (v9), Feather Icons (`react-feather`)
- **Routing**: React Router DOM v6
- **Styling**: SCSS / SASS
- **Hosting**: Firebase Hosting (`firebase.json`)

## Prerequisites

- Node.js (v16 or v18 recommended)
- Package manager (`yarn` or `npm`)

## Getting Started

1. **Install dependencies**:
   ```bash
   yarn install
   # or
   npm install
   ```

2. **Run the Development Server**:
   ```bash
   yarn dev
   # or
   npm run dev
   ```

3. **Access the Application**:
   Open `http://localhost:5173` in your web browser.

## Available Scripts

- `yarn dev` - Starts the local Vite development server with HMR.
- `yarn build` - Compiles and generates production PWA bundles.
- `yarn preview` - Locally previews the production build.
